🔐 ស្វាគមន៍មកកាន់ Cybersecurity

Cybersecurity គឺជាការការពារ Computer, Network, Applications និង Data ពីការគំរាមកំហែង និងការចូលប្រើ ដែលគ្មានការអនុញ្ញាត។

💡 គោលបំណង៖ រៀនពីវិធីការពារគណនី ទិន្នន័យ ឧបករណ៍ និងប្រព័ន្ធឱ្យមានសុវត្ថិភាព។
CHAPTER 01

សេចក្ដីផ្ដើមអំពី Cybersecurity

Cybersecurity គឺជាវិធីសាស្ត្រ និងបច្ចេកវិទ្យា សម្រាប់ការពារប្រព័ន្ធកុំព្យូទ័រ Network និងព័ត៌មាន។

  • ការពារ Computer
  • ការពារ Network
  • ការពារ Personal Data
  • ការពារ Online Accounts
CHAPTER 02

CIA Triad

CIA Triad គឺជាគោលការណ៍សំខាន់ ៣ យ៉ាងក្នុង Cybersecurity។

  • Confidentiality – រក្សាព័ត៌មានឱ្យមានភាពសម្ងាត់
  • Integrity – រក្សាភាពត្រឹមត្រូវរបស់ទិន្នន័យ
  • Availability – ធានាឱ្យប្រព័ន្ធអាចប្រើបាន
CHAPTER 03

Cyber Threats

Cyber Threat គឺជាហានិភ័យ ឬការគំរាមកំហែង ដែលអាចប៉ះពាល់ដល់ Computer Network ឬ Data។

  • Malware
  • Phishing
  • Password Attacks
  • Social Engineering
  • Data Theft
CHAPTER 04

Malware

Malware គឺជា Software ដែលត្រូវបានបង្កើត ដើម្បីធ្វើសកម្មភាពដែលអាចបង្កគ្រោះថ្នាក់ ឬប៉ះពាល់ដល់ប្រព័ន្ធ។

  • Virus
  • Worm
  • Trojan
  • Ransomware
  • Spyware
🛡️ កុំដំឡើងកម្មវិធីពីប្រភពដែលមិនគួរឱ្យទុកចិត្ត និងត្រូវ Update Software ជាប្រចាំ។
CHAPTER 05

Phishing

Phishing គឺជាវិធីបោកបញ្ឆោតអ្នកប្រើប្រាស់ ដើម្បីឱ្យបង្ហាញព័ត៌មានសម្ងាត់ ដូចជា Password ឬព័ត៌មានគណនី។

  • Email Phishing
  • SMS Phishing
  • Fake Login Pages
  • Social Media Scams
⚠️ កុំចុច Link ដែលមិនស្គាល់ ហើយត្រូវពិនិត្យ URL មុនពេល Login។
CHAPTER 06

Password Security

Password គឺជាវិធីសំខាន់មួយសម្រាប់ការពារ Account។ Password គួរតែមានភាពរឹងមាំ និងមិនគួរប្រើ Password ដូចគ្នាសម្រាប់គ្រប់ Account។

  • ប្រើ Password វែង
  • ប្រើអក្សរធំ និងអក្សរតូច
  • បញ្ចូលលេខ
  • ប្រើ Symbols
  • កុំប្រើព័ត៌មានផ្ទាល់ខ្លួន
CHAPTER 07

Authentication

Authentication គឺជាដំណើរការផ្ទៀងផ្ទាត់ថា អ្នកប្រើប្រាស់គឺជាមនុស្សដែលមានសិទ្ធិចូលប្រើ។

  • Password
  • PIN
  • Fingerprint
  • Face Recognition
  • Two-Factor Authentication (2FA)
CHAPTER 08

Network Security

Network Security គឺជាការការពារ Network ពីការចូលប្រើដោយគ្មានការអនុញ្ញាត និងការគំរាមកំហែងផ្សេងៗ។

  • Secure Wi-Fi
  • Firewall
  • Encryption
  • Network Monitoring
CHAPTER 09

Firewalls

Firewall គឺជាប្រព័ន្ធដែលជួយត្រួតពិនិត្យ និងគ្រប់គ្រង Network Traffic ចូល និងចេញពីប្រព័ន្ធ។

🛡️ Firewall អាចជួយទប់ស្កាត់ Traffic ដែលមិនគួរឱ្យទុកចិត្ត តាមរយៈច្បាប់ដែលបានកំណត់។
CHAPTER 10

Encryption

Encryption គឺជាដំណើរការបម្លែងទិន្នន័យ ទៅជាទម្រង់ដែលមិនអាចអានបានដោយងាយ ដោយអ្នកដែលគ្មានសិទ្ធិ។

  • Encryption
  • Decryption
  • Encryption Key
  • HTTPS
CHAPTER 11

Web Security

Web Security គឺជាការការពារ Website និង Web Applications ពីការគំរាមកំហែង។

  • HTTPS
  • Secure Authentication
  • Input Validation
  • Secure Cookies
  • Software Updates
CHAPTER 12

Social Engineering

Social Engineering គឺជាការប្រើបច្ចេកទេស បញ្ចុះបញ្ចូល ឬបោកបញ្ឆោតមនុស្ស ដើម្បីទទួលបានព័ត៌មាន ឬសិទ្ធិចូលប្រើ។

  • Phishing
  • Impersonation
  • Fake Support
  • Scam Messages
CHAPTER 13

Data Security

Data Security គឺជាការការពារទិន្នន័យ ពីការបាត់បង់ ការលួច និងការចូលប្រើ ដោយគ្មានការអនុញ្ញាត។

  • Data Encryption
  • Access Control
  • Backup
  • Data Classification
CHAPTER 14

Access Control

Access Control គឺជាការកំណត់ថា អ្នកណាអាចចូលប្រើ Resource ណាមួយ និងអាចធ្វើអ្វីបានខ្លះ។

  • User Accounts
  • Permissions
  • Roles
  • Least Privilege
CHAPTER 15

Wi-Fi Security

Wi-Fi Security ជួយការពារ Wireless Network ពីការចូលប្រើដោយគ្មានការអនុញ្ញាត។

  • ប្រើ Strong Wi-Fi Password
  • ប្រើ WPA2 ឬ WPA3 នៅពេលមានជម្រើស
  • Update Router Firmware
  • បិទការកំណត់ដែលមិនចាំបាច់
CHAPTER 16

Mobile Security

Mobile Security គឺជាការការពារ Smartphone និង Tablet ពីការគំរាមកំហែង។

  • Screen Lock
  • App Permissions
  • System Updates
  • Trusted App Stores
  • Device Backup
CHAPTER 17

Cloud Security

Cloud Security គឺជាការការពារទិន្នន័យ និង Services ដែលដំណើរការនៅលើ Cloud។

Incident Response

Incident Response គឺជាដំណើរការឆ្លើយតប នៅពេលមាន Security Incident។

Backup & Recovery

Backup ជួយរក្សាច្បាប់ចម្លងទិន្នន័យ ដើម្បីអាចស្ដារទិន្នន័យឡើងវិញ នៅពេលមានបញ្ហា។
