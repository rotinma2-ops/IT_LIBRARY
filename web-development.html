សេចក្ដីផ្ដើមអំពី Web Development

  • Frontend Development
  • Backend Development
  • Database
  • Web Hosting

  • Client
  • Server
  • HTTP / HTTPS
  • Request
  • Response
CHAPTER 03

មូលដ្ឋាន HTML

HTML (HyperText Markup Language) ប្រើសម្រាប់បង្កើត Structure របស់ Website។

HTML Example
<h1>Hello World</h1>
<p>Welcome to my website.</p>
CHAPTER 04

HTML Elements

HTML មាន Elements ជាច្រើនសម្រាប់បង្ហាញ Content ផ្សេងៗនៅលើ Website។

  • Heading
  • Paragraph
  • Image
  • Link
  • Button
  • List
CHAPTER 05

HTML Forms

Form ប្រើសម្រាប់ទទួលទិន្នន័យពី User ដូចជា Login, Register និង Contact Form។ 

<form>
    <input type="text">
    <input type="email">
    <button>Submit</button>
</form>
CHAPTER 06

មូលដ្ឋាន CSS

CSS (Cascading Style Sheets) ប្រើសម្រាប់រចនា Website ដូចជា ពណ៌ ទំហំ និង Layout។ 

body {
    background: #f4f7fb;
}

h1 {
    color: blue;
}
CHAPTER 07

CSS Selectors

Selector ប្រើសម្រាប់ជ្រើសរើស HTML Element ដែលយើងចង់កែប្រែ Style។

  • Element Selector
  • Class Selector
  • ID Selector
  • Attribute Selector
CHAPTER 08

Colors និង Fonts

CSS អាចកំណត់ពណ៌ និង Font ដើម្បីធ្វើឱ្យ Website មានភាពស្រស់ស្អាត និងងាយស្រួលអាន។ 

body {
    font-family: Arial;
    color: #1e293b;
}

h1 {
    color: #2563eb;
}
CHAPTER 09

CSS Box Model

Box Model ជាគោលគំនិតសំខាន់ក្នុង CSS ដែលរួមមាន Content, Padding, Border និង Margin។

📦 Content → Padding → Border → Margin
CHAPTER 10

Flexbox

Flexbox ជា CSS Layout System ដែលជួយរៀបចំ Elements នៅក្នុង Container ឱ្យមានភាពងាយស្រួល។ 

.container {
    display: flex;
    justify-content: center;
    align-items: center;
}
CHAPTER 11

CSS Grid

CSS Grid ប្រើសម្រាប់បង្កើត Layout ជាជួរ និងជួរឈរ។ 

.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 20px;
}
CHAPTER 12

Responsive Design

Responsive Design ធ្វើឱ្យ Website អាចបង្ហាញបានល្អនៅលើ Computer, Tablet និង Mobile។

📱 Website គួរតែអាចសម្របខ្លួនទៅតាមទំហំ Screen។
CHAPTER 13

JavaScript

JavaScript គឺជា Programming Language ដែលប្រើសម្រាប់បន្ថែម Interaction និង Dynamic Behavior ទៅ Website។ 

console.log("Hello World");
CHAPTER 14

JavaScript Variables

Variable ប្រើសម្រាប់រក្សាទុកទិន្នន័យ ដែលកម្មវិធីត្រូវការប្រើប្រាស់។ 

let name = "Dara";
const age = 20;

console.log(name);
console.log(age);
CHAPTER 15

JavaScript Functions

Function គឺជាប្លុក Code ដែលអាចហៅមកប្រើឡើងវិញ។ 

function greet(name) {
    return "Hello " + name;
}

console.log(greet("Dara"));
CHAPTER 16

DOM

DOM (Document Object Model) អនុញ្ញាតឱ្យ JavaScript ចូលប្រើ និងកែប្រែ HTML Elements។ 

document.getElementById("title")
    .textContent = "Hello!";
CHAPTER 17

JavaScript Events

Event គឺជាសកម្មភាពដែលកើតឡើង ដូចជា Click, Submit, Mouse Move និង Keyboard Input។ 

button.addEventListener("click", function() {
    alert("Button clicked!");
});
CHAPTER 18

Web APIs

API អនុញ្ញាតឱ្យកម្មវិធីផ្សេងៗ អាចទំនាក់ទំនង និងផ្លាស់ប្ដូរទិន្នន័យគ្នា។

  • REST API
  • JSON
  • HTTP Requests
  • Fetch API
CHAPTER 19

Web Security

Web Security គឺជាការការពារ Website និង User Data ពីការគំរាមកំហែង។

  • HTTPS
  • Strong Authentication
  • Input Validation
  • Secure Passwords
  • Software Updates
🛡️ ត្រូវរក្សាទុក Password និង Personal Information ឱ្យមានសុវត្ថិភាព។

Web Development Project
