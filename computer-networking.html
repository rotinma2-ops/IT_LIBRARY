🌐 ស្វាគមន៍មកកាន់ Computer Networking

Computer Networking គឺជាចំណេះដឹងអំពីរបៀបដែល Computer និងឧបករណ៍ផ្សេងៗភ្ជាប់ទំនាក់ទំនងគ្នា ដើម្បីផ្លាស់ប្ដូរទិន្នន័យ និងប្រើប្រាស់ធនធានរួម។

💡 ចំណាំ៖ មេរៀននេះរៀបចំពីមូលដ្ឋាន Network រហូតដល់ប្រធានបទដែលប្រើប្រាស់ក្នុង Network សម័យទំនើប។
CHAPTER 01

សេចក្ដីផ្ដើមអំពី Computer Networking

Computer Network គឺជាប្រព័ន្ធដែលអនុញ្ញាតឱ្យ Computer និងឧបករណ៍ផ្សេងៗទំនាក់ទំនងគ្នា និងផ្លាស់ប្ដូរទិន្នន័យតាមរយៈ Connection។

ឧទាហរណ៍៖ Computer នៅក្នុងការិយាល័យ អាចភ្ជាប់គ្នា ដើម្បីចែករំលែក File, Printer និង Internet។

CHAPTER 02

ប្រភេទនៃ Network

Network អាចបែងចែកជាប្រភេទផ្សេងៗ ដោយផ្អែកលើទំហំ និងតំបន់ដែលវាគ្របដណ្ដប់។

  • PAN — Personal Area Network
  • LAN — Local Area Network
  • MAN — Metropolitan Area Network
  • WAN — Wide Area Network
CHAPTER 03

Network Topology

Network Topology គឺជារបៀបដែលឧបករណ៍ ត្រូវបានរៀបចំ និងភ្ជាប់គ្នានៅក្នុង Network។

  • ⭐ Star Topology
  • 🚌 Bus Topology
  • ⭕ Ring Topology
  • 🌳 Tree Topology
  • 🕸️ Mesh Topology
CHAPTER 04

Network Devices

Network Devices គឺជាឧបករណ៍ដែលប្រើសម្រាប់ បង្កើត និងគ្រប់គ្រង Network។

  • 🔀 Switch
  • 🚪 Router
  • 📡 Access Point
  • 🔌 Modem
  • 🛡️ Firewall
  • 🔁 Repeater
CHAPTER 05

LAN, MAN និង WAN

LAN គ្របដណ្ដប់តំបន់តូច ដូចជា ផ្ទះ សាលារៀន ឬការិយាល័យ។

MAN អាចគ្របដណ្ដប់តំបន់ធំជាង LAN ដូចជាតំបន់ទីក្រុង។

WAN គ្របដណ្ដប់តំបន់ធំខ្លាំង និងអាចភ្ជាប់ Network នៅទីតាំងផ្សេងៗគ្នា។

CHAPTER 06

Internet និង Intranet

Internet គឺជាបណ្ដាញធំដែលភ្ជាប់ Network ជាច្រើននៅទូទាំងពិភពលោក។

Intranet គឺជា Network ផ្ទៃក្នុងដែលប្រើប្រាស់ នៅក្នុងអង្គការ ឬស្ថាប័ន។

CHAPTER 07

IP Address

IP Address គឺជាអាសយដ្ឋានដែលប្រើសម្រាប់ កំណត់អត្តសញ្ញាណឧបករណ៍នៅក្នុង Network។

Example IPv4 
192.168.1.10

IP Address ជួយឱ្យឧបករណ៍អាចស្វែងរក និងទំនាក់ទំនងជាមួយឧបករណ៍ផ្សេងទៀត។

CHAPTER 08

IPv4 Addressing

IPv4 គឺជាប្រព័ន្ធ Addressing ដែលប្រើ អាសយដ្ឋានទំហំ 32-bit។

Example IPv4 Address 
192.168.1.1
10.0.0.1
172.16.0.1
CHAPTER 09

Subnetting

Subnetting គឺជាវិធីបែងចែក Network ធំមួយ ទៅជា Network តូចៗជាច្រើន។

Example Subnet Mask 
255.255.255.0

CIDR:
/24
💡 Subnetting អាចជួយរៀបចំ Network និងគ្រប់គ្រង IP Address ឱ្យមានប្រសិទ្ធភាព។
CHAPTER 10

IPv6

IPv6 ត្រូវបានបង្កើតឡើងដើម្បីផ្ដល់ IP Address ច្រើនជាង IPv4។

Example IPv6 Address 
2001:db8::1

Network Security

Network Security គឺជាការការពារ Network និងទិន្នន័យពីការចូលប្រើដោយគ្មានការអនុញ្ញាត និងការគំរាមកំហែងផ្សេងៗ។

  • Password Security
  • Encryption
  • Authentication
  • VPN
