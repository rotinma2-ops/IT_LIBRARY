CHAPTER 01

សេចក្ដីផ្ដើមអំពី Database

Database គឺជាបណ្តុំទិន្នន័យដែលត្រូវបានរៀបចំ ដើម្បីឱ្យងាយស្រួលក្នុងការរក្សាទុក ស្វែងរក និងគ្រប់គ្រង។

  • រក្សាទុកព័ត៌មាន
  • ស្វែងរកទិន្នន័យ
  • កែប្រែទិន្នន័យ
  • លុបទិន្នន័យ
CHAPTER 02

Database Concepts

Database មានធាតុសំខាន់ៗជាច្រើន ដែលធ្វើការជាមួយគ្នាដើម្បីគ្រប់គ្រងទិន្នន័យ។

  • Database
  • Table
  • Record
  • Field
  • Relationship
CHAPTER 03

DBMS

DBMS (Database Management System) គឺជា Software ដែលប្រើសម្រាប់បង្កើត និងគ្រប់គ្រង Database។

  • MySQL
  • PostgreSQL
  • Oracle Database
  • Microsoft SQL Server
  • SQLite
CHAPTER 04

Database Models

Database Model គឺជាវិធីសម្រាប់រៀបចំ និងបង្ហាញទំនាក់ទំនងរបស់ទិន្នន័យ។

  • Relational Database
  • Hierarchical Database
  • Network Database
  • NoSQL Database
CHAPTER 05

Tables

Table គឺជាកន្លែងសម្រាប់រក្សាទុកទិន្នន័យ ក្នុង Relational Database។

SQL Example 
CREATE TABLE students (
    id INT,
    name VARCHAR(100),
    age INT
);
CHAPTER 06

Primary Key

Primary Key គឺជា Column ដែលប្រើសម្រាប់ កំណត់អត្តសញ្ញាណ Record នីមួយៗឱ្យមានភាពខុសគ្នា។

SQL Example 
CREATE TABLE students (
    id INT PRIMARY KEY,
    name VARCHAR(100)
);
CHAPTER 07

Foreign Key

Foreign Key ប្រើសម្រាប់បង្កើតទំនាក់ទំនង រវាង Table ពីរ ឬច្រើន។

SQL Example 
CREATE TABLE orders (
    id INT PRIMARY KEY,
    student_id INT,
    FOREIGN KEY (student_id)
    REFERENCES students(id)
);
CHAPTER 08

Relationships

Relationship គឺជាទំនាក់ទំនងរវាង Table។

  • One-to-One
  • One-to-Many
  • Many-to-Many
CHAPTER 09

SQL

SQL (Structured Query Language) គឺជាភាសាសម្រាប់ធ្វើការជាមួយ Relational Database។

SQL Example 
CREATE DATABASE school;
CHAPTER 10

SELECT Statement

SELECT ប្រើសម្រាប់ទាញយកទិន្នន័យ ពី Database។

SQL 
SELECT * FROM students;
SELECT name, age
FROM students;
CHAPTER 11

INSERT Statement

INSERT ប្រើសម្រាប់បញ្ចូល Record ថ្មី ទៅក្នុង Table។

SQL 
INSERT INTO students
(id, name, age)
VALUES
(1, 'Dara', 20);
CHAPTER 12

UPDATE Statement

UPDATE ប្រើសម្រាប់កែប្រែទិន្នន័យ ដែលមានស្រាប់។

SQL 
UPDATE students
SET age = 21
WHERE id = 1;
CHAPTER 13

DELETE Statement

DELETE ប្រើសម្រាប់លុប Record ចេញពី Table។

SQL 
DELETE FROM students
WHERE id = 1;
⚠️ ត្រូវប្រើ WHERE ដោយប្រុងប្រយ័ត្ន ពេលប្រើ DELETE។
CHAPTER 14

JOIN

JOIN ប្រើសម្រាប់ភ្ជាប់ទិន្នន័យពី Table ដែលមានទំនាក់ទំនងគ្នា។

SQL 
SELECT students.name, orders.id
FROM students
JOIN orders
ON students.id = orders.student_id;
CHAPTER 15

Database Normalization

Normalization គឺជាដំណើរការរៀបចំ Database ដើម្បីកាត់បន្ថយ Data Redundancy និងធ្វើឱ្យទិន្នន័យមានរចនាសម្ព័ន្ធល្អ។

  • 1NF
  • 2NF
  • 3NF
CHAPTER 16

ER Diagram

ER Diagram (Entity Relationship Diagram) ប្រើសម្រាប់បង្ហាញ Entity និង Relationship នៅក្នុង Database។

  • Entity
  • Attribute
  • Relationship
CHAPTER 17

Database Transactions

Transaction គឺជាក្រុមនៃប្រតិបត្តិការដែលត្រូវបាន ប្រតិបត្តិជាឯកតាមួយ។

SQL 
START TRANSACTION;

UPDATE accounts
SET balance = balance - 100
WHERE id = 1;

COMMIT;
CHAPTER 18

Database Security

Database Security គឺជាការការពារ Database ពីការចូលប្រើដែលគ្មានការអនុញ្ញាត និងការបាត់បង់ទិន្នន័យ។

  • Authentication
  • Authorization
  • Access Control
  • Encryption
  • Strong Passwords
CHAPTER 19

Backup & Recovery

Database Backup គឺជាការរក្សាទុកច្បាប់ចម្លង នៃទិន្នន័យ ដើម្បីអាចយកមកប្រើវិញ នៅពេលមានបញ្ហា។

  • Full Backup
  • Incremental Backup
  • Differential Backup
  • Database Recovery
CHAPTER 20

Database Project

បន្ទាប់ពីរៀន Database Systems អ្នកអាចអនុវត្តដោយបង្កើត Project មួយ។

  • 👨‍🎓 Student Management System
  • 📚 Library Management System
  • 🛒 Online Shop Database
  • 🏫 School Management System
  • 🏥 Hospital Management System
Example Database 
CREATE DATABASE school;

USE school;

CREATE TABLE students (
    id INT PRIMARY KEY,
    name VARCHAR(100),
    age INT,
    email VARCHAR(150)
);
