🐍 ស្វាគមន៍មកកាន់ Python Programming

សៀវភៅនេះត្រូវបានរៀបចំឡើងសម្រាប់អ្នកដែលចង់រៀន Python Programming ចាប់ពីកម្រិតមូលដ្ឋាន។ មេរៀនត្រូវបានរៀបចំជាជំហានៗ ដើម្បីឱ្យអ្នកអាច រៀន និងអនុវត្ត Code បានយ៉ាងងាយស្រួល។

💡 គន្លឹះ៖ កុំគ្រាន់តែអាន Code។ សូមសាកល្បងសរសេរ និង Run Code ដោយខ្លួនឯង ដើម្បីឱ្យយល់បានកាន់តែច្បាស់។
CHAPTER 01

សេចក្ដីផ្ដើមអំពី Python

Python គឺជាភាសាកម្មវិធីមួយដែលមាន Syntax ងាយស្រួលអាន និងសរសេរ។ Python ត្រូវបានប្រើ ក្នុង Web Development, Data Science, Artificial Intelligence, Automation និង Software Development។

Python Example 
print("សួស្តី Python!")
✅ ចំណាំ៖ print() ប្រើសម្រាប់បង្ហាញព័ត៌មាន នៅលើអេក្រង់។
CHAPTER 02

ការដំឡើង Python និងកម្មវិធីដំបូង

ដើម្បីចាប់ផ្ដើមរៀន Python អ្នកត្រូវដំឡើង Python និងអាចប្រើ Visual Studio Code សម្រាប់សរសេរ Code។

Python Hello World 
print("Hello World")

Code ខាងលើនឹងបង្ហាញ Hello World នៅលើអេក្រង់។

CHAPTER 03

Variables — អថេរ

Variable គឺជាកន្លែងសម្រាប់រក្សាទុកទិន្នន័យ។ យើងអាចប្រើ Variable ដើម្បីរក្សាទុកឈ្មោះ អាយុ លេខ និងព័ត៌មានផ្សេងៗ។

Python Variables 
name = "Dara"
age = 20

print(name)
print(age)
CHAPTER 04

Data Types — ប្រភេទទិន្នន័យ

Python មានប្រភេទទិន្នន័យជាច្រើនសម្រាប់ រក្សាទុកព័ត៌មានផ្សេងៗ។

  • String — អក្សរ
  • Integer — ចំនួនគត់
  • Float — ចំនួនទសភាគ
  • Boolean — True / False
  • List — បញ្ជី
  • Tuple — បញ្ជីមិនអាចកែប្រែ
  • Dictionary — Key / Value
Python Data Types 
name = "Dara"
age = 20
height = 1.75
student = True
CHAPTER 05

Operators — ប្រមាណវិធី

Operators ប្រើសម្រាប់ធ្វើប្រតិបត្តិការលើទិន្នន័យ។

Python Operators 
a = 10
b = 3

print(a + b)
print(a - b)
print(a * b)
print(a / b)
print(a % b)
CHAPTER 06

Input និង Output

input() ប្រើសម្រាប់ទទួលព័ត៌មាន ពីអ្នកប្រើប្រាស់។

Python User Input 
name = input("បញ្ចូលឈ្មោះរបស់អ្នក: ")

print("សួស្តី", name)
CHAPTER 07

If, Elif និង Else

Conditional Statements ប្រើសម្រាប់ឱ្យកម្មវិធី ធ្វើការសម្រេចចិត្តតាមលក្ខខណ្ឌ។

Python Conditions 
age = 18

if age >= 18:
    print("អ្នកជាមនុស្សពេញវ័យ")
else:
    print("អ្នកមិនទាន់ពេញវ័យ")
CHAPTER 08

For Loop

For Loop ប្រើសម្រាប់ដំណើរការ Code ដដែលៗ ជាច្រើនដង។

Python For Loop 
for i in range(5):
    print(i)
CHAPTER 09

While Loop

While Loop ដំណើរការដរាបណាលក្ខខណ្ឌ នៅតែមានតម្លៃ True។

Python While Loop 
number = 1

while number <= 5:
    print(number)
    number += 1
CHAPTER 10

Lists — បញ្ជី

List អាចរក្សាទុកទិន្នន័យជាច្រើននៅក្នុង Variable មួយ។

Python Lists 
students = ["Dara", "Sokha", "Mony"]

print(students[0])

students.append("Kimsan")
CHAPTER 11

Tuples

Tuple មានលក្ខណៈស្រដៀង List ប៉ុន្តែទិន្នន័យ នៅក្នុង Tuple មិនអាចកែប្រែបាន។

Python Tuple 
colors = ("Red", "Green", "Blue")

print(colors[0])
CHAPTER 12

Dictionaries

Dictionary រក្សាទុកទិន្នន័យជាគូ Key និង Value។

Python Dictionary 
student = {
    "name": "Dara",
    "age": 20,
    "major": "IT"
}

print(student["name"])
CHAPTER 13

Functions — អនុគមន៍

Function គឺជាក្រុម Code ដែលអាចហៅប្រើឡើងវិញបាន។ វាជួយរៀបចំកម្មវិធីឱ្យមានរបៀបរៀបរយ។

Python Function 
def greeting(name):
    print("សួស្តី", name)

greeting("Dara")
CHAPTER 14

Modules

Module គឺជា Python File ដែលអាចយក Code ទៅប្រើក្នុងកម្មវិធីផ្សេងទៀត។

Python Modules 
import math

print(math.sqrt(25))
CHAPTER 15

File Handling

Python អាចអាន និងសរសេរ File បាន។

Python File Handling 
file = open("data.txt", "r")

content = file.read()

print(content)

file.close()
CHAPTER 16

Error Handling

Python ប្រើ Try និង Except ដើម្បីគ្រប់គ្រង Error ដែលអាចកើតឡើងនៅពេលកម្មវិធីដំណើរការ។

Python Error Handling 
try:
    number = int(input("បញ្ចូលលេខ: "))
    print(number)

except:
    print("សូមបញ្ចូលលេខត្រឹមត្រូវ")
CHAPTER 17

Object-Oriented Programming

Python គាំទ្រ Object-Oriented Programming (OOP)។ យើងអាចបង្កើត Class និង Object ដើម្បីរៀបចំកម្មវិធី។

Python OOP 
class Student:

    def __init__(self, name):
        self.name = name

student = Student("Dara")

print(student.name)
